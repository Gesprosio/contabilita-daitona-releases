# Contabilità Daitona

Questo repository contiene solo gli **installer** di Contabilità Daitona e le informazioni per gli
**aggiornamenti automatici**. Il codice sorgente non è qui e non ci sono dati dei clienti.

- Scaricare l'ultima versione: sezione **Releases** → `Contabilita-Daitona-Setup-x.y.z.exe`
- Il programma installato controlla da solo se c'è una versione nuova e chiede prima di installarla.
- Alla prima installazione Windows può mostrare "Windows ha protetto il PC": cliccare
  "Ulteriori informazioni" e poi "Esegui comunque".
